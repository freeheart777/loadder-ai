# Loadder AI Agent Rules

## Core Principle
Intent First:
User Intent → Business Understanding → Brand Context → Service Execution

## Source of Truth
- Business Context
- Brand DNA
- Brand Book
- Customer Journey

## Never Do
- Create duplicate onboarding systems
- Create duplicate business models
- Generate content before understanding the business need
- Modify database structure without migration review
- Bypass existing architecture without analysis

## Development Rule
Before every change:
1. Understand current architecture
2. Identify affected files
3. Make the smallest safe change
4. Run relevant tests
5. Commit with a clear message

## Current Direction
Build business understanding first, then recommend and execute services.
