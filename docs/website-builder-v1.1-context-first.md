# Website Builder v1.1 — Business Context-first

## Contract

Website creation starts from the active Business Context. The existing Business Profile → Business DNA → Brand Book → Business Context chain remains authoritative.

The creation screen may suggest editable site name, slug, preset, and CTA destination. It never fabricates a CTA destination. If an active Context is unavailable or stale, creation is blocked and the user is sent back through the existing onboarding path.

The existing Website Builder remains the editing surface after project creation; blueprint versioning, visual recommendations, preview, and publication guards are unchanged.
