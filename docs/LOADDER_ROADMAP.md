# Loadder Product Roadmap

## Vision
Loadder is a Commerce Operating System, not only a website builder.

Core direction:

Business DNA -> Business Memory -> AI Commerce Core -> Commerce Engine -> Visual Studio -> Storefront

## Phase 1 - Commerce Foundation

- Product Flow
  - Select existing catalog product
  - Create new product from browser
  - Upload product images
  - Media Library integration
  - SEO/GEO product content
  - Insert product into Studio section

- Commerce Blocks
  - Product Showcase
  - Product Categories
  - Promotion Blocks
  - Hero/Banner Engine

## Phase 2 - Visual Commerce Studio

- Canvas editing
- Click-to-edit experience
- Block Library
- Templates
- Theme system

## Phase 3 - Intelligence Layer

- Business Memory
- Analytics
- Conversion insights
- Experiment engine

## Phase 4 - AI Workforce

Agents:
- Store Designer Agent
- Product Content Agent
- Marketing Agent
- Conversion Agent
- Analyst Agent

## Phase 5 - Marketplace

- Template Marketplace
- Block Marketplace
- AI Agent Marketplace
- Plugin Ecosystem

## Principles

- Quality by design (TQM)
- Real execution over simulated progress
- Performance first
- SEO/GEO ready
- Lightweight storefront
- Scalable architecture
