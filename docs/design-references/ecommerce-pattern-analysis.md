# Architecture Rule

Websites are not templates.

A website is:

Core Website Engine
+
Enabled Capabilities
+
Selected Sections
+
Theme

Example:

Kitchen Store:

Capabilities:
- commerce
- content
- forms

Electronics Store:

Capabilities:
- commerce
- content
- campaigns

Music Academy:

Capabilities:
- courses
- booking
- people
- commerce
